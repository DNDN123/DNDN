SMART-MLFQ · LLM FOR OS · 인터랙티브 데모

말로 입력하면 OS 스케줄러가 움직입니다

자연어 한 줄 → LLM이 큐 레벨(0/1/2)로 번역 → 우리가 xv6 커널에 구현한 3-단계 MLFQ가 실제로 스케줄링. LLM은 커널에 들어오지 않습니다 — 2비트 힌트만 주고, 잘못 줘도 OS가 스스로 교정합니다.

1 자연어 → 큐 레벨 번역

예시 칩은 실제 Solar Pro 3 라이브 응답(2026-06-03 캡처). 직접 입력하면 키워드 휴리스틱(오프라인)으로 번역합니다.

번역 출처 큐 레벨 실행 프로그램 판단 이유
xv6 명령   $ nlrun

2 3-단계 MLFQ 스케줄러 (실제 커널 상수 반영)

레벨별 타임슬라이스 {2, 4, 8} tick, 100 tick마다 전체 boost — 실제 kernel/proc.c 값 그대로.

tick 0  ·  다음 boost까지 100  ·  실행 중 —
무엇을 보나: ① 내가 투입한 작업(보라)이 LLM이 정한 큐에서 시작 · ② CPU 독식 프로세스(cpu_hog)는 타임슬라이스를 다 쓰면 HIGH→MID→LOW로 자동 강등(self-correction) · ③ I/O 작업은 블록될 때 큐 레벨 유지(강등 안 됨) · ④ 100 tick마다 boost로 전부 HIGH 복귀(starvation 방지).
이 데모의 번역 로직·MLFQ 상수는 실제 저장소 코드(integration/host/nl_shell.py, integration/xv6-riscv/kernel/proc.c)와 일치합니다.
